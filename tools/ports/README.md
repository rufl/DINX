# ports

Build recipes for software DINX packages but does not author: upstream tarballs, AppImages and
third-party runtimes staged by the package pipeline.

This directory is a placeholder. FreeBSD port Makefiles live in `distro/bsd/ports/` and the Linux
recipes live in `distro/packages/<name>/`. New content only lands here once a recipe exists that
belongs to neither of those trees.

See [docs/dinxtools.md](../../docs/dinxtools.md) for the inventory and the rules for this line.
